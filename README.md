# ChatSched Sport

ChatSched Sport is the new **Sports Opportunity Network**. It is a separate product and repository from the existing ChatSched advertising platform.

## Vision
DISCOVER → MATCH → DEVELOP → CONNECT → REPRESENT → GROW

The platform is designed to connect athletes with clubs, scouts, academies, coaches, brands, sponsors, agents and events.

## Stack
React 19 · TypeScript · Vite · Tailwind CSS · Supabase/PostgreSQL · Cloudflare

## Development rule
INSPECT → PLAN → IMPLEMENT → TEST → AUDIT → COMMIT → PUSH

Never claim a build, test, deployment or push has succeeded unless it has actually been verified.
